# CustomServiceAgent 开发集对照评测

运行日期为 2026-11-04。使用同一批 20 道政策开发题，包含 16 道单跳和 4 道多证据题。通过真实 Milvus、Elasticsearch、重排及聊天模型生成四组答案。固定 Top-5 是在现行服务中关闭自适应重排与 Agentic RAG 的策略对照。所有配置使用相同的语料、模型和最终 Top-5 上限。

回答模型为 `deepseek-flash`。Judge 为 `deepseek-flash`，量表 `claims-v2`。三项回答指标独立复评，Judge 看不到配置名称。回答和 Judge 使用同系列配置，评分仅作开发诊断。

## 发现与限制

- 工单优先级、首响和建单复用题 `dev-policy-017` 同时需要三组证据。三种新策略均漏了一组。两组 Agentic RAG 均将此题路由到普通路径，且各自在四道多证据题中只触发两次。需要补足并列子诉求的路由识别，再比较截断策略。
- RRF 组另漏掉 `dev-policy-010` 的过敏反馈证据。当前开发结果不足以支持将 RRF 或分数断层截断用作统一默认。正式参数继续留待独立验收。
- 各项均为描述性分数。配对样本数、成对差和 bootstrap 95% 区间在结果 JSON 中，可用于核对样本缺失影响。
- DST 六条开发用例的完整标注槽位命中从 1/6 到 6/6，订单槽位从 3/6 到 6/6。此项测历史与 DST 解析，端到端 Agent 任务成功率与 pass³ 尚未测。
- Judge 校准题使用八条合成参考，忠实度、相关性、正确性的精确一致分别为 7/8、7/8、8/8。旧政策被忠实转述的一题仍有分歧，正式独立人工校准尚未完成。
- 正式验收计数为 0，严格门槛仍拦截。新增 24 条含证据和答案的政策候选、28 条流程开发题和 8 条合成 Judge 校准题。安全与幂等应由权限及业务状态断言验收。
